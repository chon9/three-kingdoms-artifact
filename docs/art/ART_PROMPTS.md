# Three Kingdoms card art: ChatGPT image prompts

This file holds **111 ready-to-paste prompts** for ChatGPT image generation, one per artwork the 三国 reskin needs: 10 heroes, 8 units, 8 items, 23 spells, 38 future heroes, 24 board & ui. The same prompts are in [`art_prompts.csv`](art_prompts.csv) (UTF-8, opens in Excel) if you prefer to work from a spreadsheet.

Every prompt is complete. Each one already contains the subject, the framing rule, the faction palette, the style block and the negative line, so you can paste it as it is.

## How to use it

1. Open a new ChatGPT chat with image generation available.
2. Copy one prompt (the grey block under each entry) and send it. Each prompt ends with the size, so ChatGPT should return a 1024x1536 portrait, a 1536x1024 landscape or a 1024x1024 square. If it returns a square for a card, reply "make it 1024x1536 portrait".
3. Check the result against the crop rules below. If it has any writing on it, or the face is in the wrong place, regenerate or use ChatGPT's edit (select area) tool to fix that part.
4. Download the PNG and save it under the exact path shown next to the entry, for example `assets/art/cards/keefe.png`.
5. For entries marked **transparent**, ask for a transparent background (the prompt already does). If the PNG comes back with a solid background, reply "same image, transparent background, PNG".

### Order of generation

1. **Guan Yu (#1) first.** He is the style anchor. Regenerate until you love him, then attach that image to every later prompt and add the line *"Match the rendering style, palette and brushwork of the attached image."*
2. **The other nine heroes**, then the **Foot Soldier** in the same session.
3. **Signature cards** right after their hero, with the hero image attached so the face matches. Each entry's note says which hero to attach (for example 长坂怒喝 needs Zhang Fei).
4. **Units, items, the remaining spells**, one faction per chat session.
5. **Future heroes** whenever you like. They are not in the game yet.
6. **Board & UI last.** Make `tower_intact` before the damaged and destroyed towers, and the main menu key art at the very end.

### Crop check before you accept an image

- **Cards:** imagine a title bar over the top 12% and a rules text box over the bottom 35% (spells) or bottom 12% (units). The face, or the key action, must be visible between them.
- **Units on the board** are cropped to the head and torso, so the face must sit in the upper-middle third.
- **Nothing important at the edges**: weapons, spear tips and bows must stay inside the frame.
- **No text anywhere**: no characters on scrolls, banners, gongs, seals or coins, no signatures and no watermarks. The game draws all names and numbers.

### Consistency tips

- Keep the style block, faction line and negative line **word for word**. Only the subject sentence changes between prompts. ChatGPT has no seed, so identical wording is the closest substitute.
- **One faction per chat session**, and start a fresh chat if the style drifts.
- **Reuse references**: attach the hero image for his signature card, `tower_intact` for the other tower states, and Da Qiao for Xiao Qiao.
- Export **PNG, not JPG**, so ink gradients do not get compression artefacts. Upscale 2x (Upscayl or Real-ESRGAN) only if the card frame shows art larger than 1024px.
- To try a different look, replace the style block paragraph in every prompt with one of the alternative style blocks below. A find-and-replace in the CSV does it in one step.

### Putting the files into the repo

- Card art goes to `assets/art/cards/<card id>.png`. The card id is the original Artifact id used in the game data, so Guan Yu is `keefe.png` and Cao Cao is `jmuy.png`.
- Future heroes go to `assets/art/heroes_reserve/<name>.png`, and board and UI art to `assets/art/ui/<name>.png`.
- Before committing, run `python tools/optimize_art.py` (add `assets/art/ui --keep-png` for transparent UI art). The game never draws art taller than 768 px, so the script replaces each oversized PNG with a 512x768 JPEG (about 120 KB) and moves the 1024x1536 master to the ignored `.tools/art_masters/`. The loader accepts `.png`, `.jpg` and `.webp`.
- Open the project in Godot once after adding files, so it creates the `.import` files, and commit those with the images.
- The game reads these paths: card art from `assets/art/cards/<id>.(png|jpg|webp)` (the frame, name, text and stats are drawn in code over it), and the optional UI files listed in the README's Artwork section. `assets/art/heroes_reserve/` is gitignored until those heroes are in the game.

### Licensing (read before committing images)

- **Only commit images you generated yourself** from these prompts. Do not commit art taken from the web, other games, or Valve's original Artifact card art.
- Only attach reference images you have the right to use: your own generations, or public-domain prints. Do not attach screenshots from other games.
- Copyright in AI-generated images is unsettled and **varies by country**. In some places (for example the United States) purely AI-generated images may not be protected by copyright at all, while others treat them differently. Under OpenAI's terms you own what you generate, to the extent the law allows.
- To keep the project easy to reuse, you can dedicate your generated images to the public domain with **CC0 1.0**, to the extent you hold any rights in them. Record that in the repo, for example in an `assets/art/LICENSE.md` that lists the files and says they were generated with ChatGPT and dedicated under CC0.
- This is not legal advice. If you plan to sell the game, check the rules where you live.

## Style bible

Every prompt is built in this order: **[subject] + [framing rule] + [faction line] + [style block] + [negative line] + [size]**. Transparent assets add one extra sentence before the size.

### Style block (default: anime-painterly over ink wash)

```text
Painterly illustration with anime influence: clean expressive faces, confident linework and soft cel-shaded figures. The figures sit on a traditional Chinese ink-wash (shuimo) background of layered grey-black washes, dry-brush mountains and drifting mist on warm aged rice paper. Small gold-leaf accents on armour edges, embroidery and sparks. Dramatic cinematic rim light against deep shadow, a restrained earthy palette lifted by one strong faction colour, Eastern Han dynasty historical detail. Rendered as polished trading card game art in a single consistent style.
```

### Framing rules

**Heroes and units (1024x1536)**

```text
Vertical portrait composition. A single main figure, shown from the waist or three-quarters up. The face and chest sit in the upper-middle third of the frame, centred horizontally. Leave the top 12% as quiet background (sky or mist) and keep the bottom 35% simple with low detail (ground, mist, robes). Weapons and limbs must not touch or cross the frame edges. The background is soft and less detailed than the figure.
```

**Tower Ship only (a vehicle instead of a figure)**

```text
Vertical portrait composition. The ship is the single main subject, shown bow-on at three-quarters. Its upper deck and banner sit in the upper-middle third of the frame, centred horizontally. Leave the top 12% as quiet background (sky or mist) and keep the bottom 35% simple with low detail (water and mist). The hull, oars and mast must not touch or cross the frame edges. The background is soft and less detailed than the ship.
```

**Spells (1024x1536)**

```text
Vertical composition showing a dramatic moment, with the main action (fire, arrows, flood, ambush) concentrated in the upper 60% of the frame. Figures can be small within the scene. The bottom third fades into dark ink wash or mist because a text box covers it. A clear focal point, with nothing important at the edges.
```

**Items (1024x1536)**

```text
A single object hero shot, centred slightly above the middle and angled at three-quarters. It floats or rests on a simple stand against a plain ink-wash backdrop with a soft gold glow behind it. No hands or characters. The object fills about 60% of the frame width, and the bottom third is empty mist.
```

**Dilu horse only**

```text
A single subject hero shot, centred slightly above the middle and angled at three-quarters, against a plain ink-wash backdrop with a soft gold glow behind it. No rider, no hands and no people. The horse fills about 60% of the frame width, and the bottom third is empty mist.
```

**Board and lane backgrounds (1536x1024)**

```text
A top-down three-quarter view of a battlefield on aged ink-wash paper with a low-contrast, even texture and no focal objects in the centre lanes, so cards stay readable on top of it.
```

**Shop, camp and other wide screens (1536x1024)**

```text
Wide landscape composition with a calm, low-detail centre band so cards stay readable on top of it, and the detail kept to the sides and lower edge.
```

**Tiling texture (1024x1024)**

```text
Seamless tileable texture with the same edges on all four sides, flat lighting and no vignette.
```

**Card back (1024x1536)**

```text
A centred symmetrical emblem made of pure ornament (cloud scrolls, dragon motif) with no text.
```

**Icons and emblems (1024x1024, transparent)**

```text
A single isolated object, centred with even padding on a transparent background, exported as a PNG with alpha. No drop-shadow ground plane.
```

**Tower and capital (1024x1536, transparent)**

```text
A Han-dynasty watchtower or fortified gate with a transparent background, layered over the board. A single isolated object, centred with even padding on a transparent background, exported as a PNG with alpha. No drop-shadow ground plane.
```

Why: on the board, units are cropped to head and torso. Spell cards cover the bottom 35% with text, and unit cards cover the bottom 12%. Keeping the lower third quiet works for both.

### Negative line (in every prompt)

```text
Do not include any text, letters, numbers, Chinese characters, calligraphy, seals, stamps, signatures, watermarks, logos, card frames, borders or UI elements. No modern objects. Do not imitate any specific video game, anime franchise or living artist's style. No extra fingers, no duplicated faces, no cropped heads.
```

Transparent assets also get:

```text
Transparent background: the ink-wash and paper texture describe only how the object itself is painted, with no backdrop behind it.
```

### Alternative style blocks

Swap one of these in place of the default style block, in every prompt, if you want a different look. Do not mix styles within the set.

**Ukiyo-e woodblock**

```text
19th-century Japanese ukiyo-e woodblock print style depicting Three Kingdoms warriors. Bold black keyline contours, flat areas of mineral pigment colour (Prussian blue, vermilion, ochre), visible wood grain and bokashi gradient skies, stylised waves, clouds and fire. Dramatic kabuki-like poses, on aged washi paper texture, with a consistent print palette across the whole set.
```

**Realistic painted**

```text
Realistic oil-and-gouache painting of a historically accurate Eastern Han dynasty warrior. Natural proportions and weathered faces, detailed lamellar armour, silk and leather. Painterly brushwork with atmospheric perspective and chiaroscuro lighting, a muted cinematic palette with one strong faction accent colour, and a misty Chinese landscape painted loosely in the background. Epic historical fantasy card illustration with a consistent style.
```
